# Demo video media credits

These credits apply to the [WildScore three-minute submission video](https://youtu.be/qNI82Sh4N70?si=1h8dzXDXGfr1D9-8), not to the WildScore processing pipeline.

## Narration

Text-to-speech narration was generated using [ElevenLabs](https://elevenlabs.io/). The generated voice is used only in the demo video. WildScore does not call ElevenLabs, and TTS is not part of the application's Meta-only runtime or saved-analysis generation.

## Visual media

- WildScore interface recordings and project field footage are used to demonstrate the saved review workflow.
- Four AI-generated camera-trap illustrations appear only as transitions. They are illustrative media, not wildlife evidence, model evaluation data or WildScore-generated results.
- The held-out wolf image is derived from USFWS Mountain-Prairie public-domain footage with a WildScore overlay.
